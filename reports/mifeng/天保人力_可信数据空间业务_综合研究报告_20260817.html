§0 元方法论

核心立场

本报告作为纵横分析法（hv-analysis）双阶段研究流中的「阶段 2 综合报告」，唯一目标 = 写深 26 章综合研究报告，逐份读取触发 1 阶段产出的 6 份专项报告正文作重点参考材料，吸收进对应章节并 in-chapter 标注来源；独立补缺（数据空白 + 行业判断 + 整合视角）。

方法论锚点

§3 第二部分 · 合作模式深度

核心立场

合作模式 = 「四方协同 + 三层飞轮 + 政策红利叠加」三栖混合结构。从数据采集到工业应用再到跨境流通，每一层都有独立价值主张 + 跨层协同红利，构成 1+1+1>3 的全链路协同。

3.1 觅蜂侧（数据采集与供给）

觅蜂在天津自贸区建立具身智能训练场 2.0 数据采集基地，部署 200-500 套 MEgo View/Gripper 数据采集终端，招募本地运营方（设备租赁 3 年折旧模式）。训练场景覆盖：3C 产线上下料、工业拆码垛、物流分拣、跨境仓储机器人。收益模式：① 设备租金（运营方按月支付）；② 数据销售（结构化数据资产 → 乘杜应用层 + 跨境数据交易）；③ 生态赋能（培训+认证+展示）。

3.2 乘杜侧（境内数据应用与工业落地）

乘杜在天津自贸区落地工业过程优化数据空间，七大核心场景训练：汽车制造 / 3C 电子 / 新能源电池 / 食品饮料 / 医药 / 化工危险品 / 有色金属。CyCore 控制器 + CyOrch 平台部署到工业客户现场，OEE 提升 ≥3% 数据飞轮迭代。收益模式：① 利润分成（OEE 提升 ≥3% 或退款）；② 模块化定价；③ 数据训练订阅费。

3.3 天津电信侧（跨境数据流通）

天津电信提供「数据跨境合规监管平台」（一站式数据跨境解决方案）：① 跨境合规预检（材料模板在线填报+智能检测+整改建议）；② 跨网申报（统一社会信用代码+经办人授权+数据出境评估申报书）；③ 数据跨境传输（跨境专线+海缆+智能算力存储+隐私计算）。收益模式：① 跨境服务费（按数据量+出境次数+复杂度）；② 申报服务费（合规预检+标准合同备案+个人信息保护认证）；③ 基础设施租赁（跨境专线+算力+存储+海外数据中心）。

§15 协议谈判清单（P0/P1/P2 优先级）

核心立场

协议谈判清单覆盖 13 项必备条款 + 7 项配套条款，P0 项（数据权属 + 跨境合规 + 退出机制）不可谈判，P1-P3 项按优先级落地。协议起草须从 P0 起步，避免在 P2-P3 项陷入拉锯而延误 P0 项落地。

15.1 P0 · 必备条款（≥ 16 项 · 不可谈判）

15.1.1 数据所有权条款（≥ 6 项）

  1. 原始数据所有权归数据提供方（神悦 / 工业客户 / 个人）
  2. 结构化数据按神悦方案「双方共有」约定（参照神悦合作方案 §3.3）
  3. 衍生数据（模型输出 / 训练数据集）按出资比例共有
  4. 数据集合（汇编作品）著作权按「选择/编排独创性」归属
  5. 数据资产入表权属清晰：来源 + 处理过程 + 授权链条 + 第三方评估
  6. 代持还原条款：觅蜂历史融资代持须在协议签署前完成还原

15.1.2 数据使用权条款（≥ 6 项）

  1. 数据使用范围：限定可信数据空间业务用途
  2. 二次分发禁止：禁止向非授权第三方转让 / 共享
  3. 使用期限：按协议约定到期终止 + 数据销毁
  4. 使用目的约束：防止超范围滥用 + 通报机制
  5. 技术措施：联邦学习 + 数据不出企业 + 差分隐私
  6. 审计机制：年度数据使用审计 + 第三方合规评估

15.1.3 跨境合规条款（≥ 6 项）

  1. 跨境数据清单：事前编制「数据出境清单」明确范围 / 数量 / 类别
  2. 跨境合规路径：选择出境评估 / 标准合同 / 个人信息保护认证
  3. 天津自贸区试点：优先利用天津自贸区数据跨境流动试点政策
  4. 天津东疆政策：参照天津东疆 2026.5 全国首单数据跨境交易路径
  5. 合规审查机制：天津电信统一合规 + 天保控股承担兜底
  6. 违规追责：跨境合规失败 → 5,000 万 / 5% 营业额处罚风险共担

15.1.4 退出机制条款（≥ 5 项）

  1. 升级深化：3 年目标达成 → 优先转为股权投资（IRR 25-35%）
  2. 合作期满退出：按协议约定退出（IRR 10-15%）
  3. 战投转让：央企 / 民营巨头并购（IRR 15-25%）
  4. 设备回购：连续 2 年里程碑未通过 → 设备资产抵押回购（IRR 5-10%）
  5. 跨境数据交易：数据产品跨境挂牌交易（IRR 12-20%）

15.2 P1 · 核心条款（可谈判）

  2. 数据资产权益：天保作为数据空间运营方享有运营权 + 数据交易分成 30%
  3. 优先回本机制：明确「神悦 → 天保」月度付费为先回本期 50% 分成

核心立场

22.1.1 按效果付费风险（乘杜 OEE 不达标）

22.1.2 数据安全事件风险

触发条件：跨境数据泄露 / 客户原始数据外泄；应对措施：① 可信数据空间「数据不出企业」架构；② 联邦学习 + 差分隐私 + 模型反演风险防控条款；③ 数据安全事件责任险（限额 ≥ 500 万元/事件）[legal-due-diligence-checklist_20260817 §11]；④ 法律追责 + 数据销毁机制。

22.1.3 跨境合规风险

触发条件：跨境合规未通过 / 2026.1.1《网络安全法》修订影响 / 国家数据局监管收紧；应对措施：① 跨境合规预检 + 跨网申报 + 数据跨境传输四重门禁 [legal-due-diligence-checklist_20260817 §10]；② 天津电信统一合规 + 天保控股承担兜底；③ 多政策对冲（自贸区试点 + 国家数据局备案 + 央企信用）。
