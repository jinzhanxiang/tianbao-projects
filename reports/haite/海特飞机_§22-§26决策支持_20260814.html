独家视角

退出路径核心洞察 = "首选战略并购 + 备选 IPO/PE"：

  1. 战略并购（首选）：航空央企（国航/南航/东航 + 中航工业）整合，符合民航产业链上下游一体化趋势；估值 15-20x EV/EBITDA ≈ 5.5-7.5 亿
  2. 独立 IPO（次选）：科创板 / 创业板是可走路径，需 3-5 年独立运营 + 关联交易透明化；估值 35-45x P/E ≈ 7-9 亿（净利润 2,000-2,500 万假设）
  3. 老股转让（备选）：PE 二手份额市场可行，估值 12-18x EV/EBITDA ≈ 4.5-6.5 亿；交易确定性高
  4. REITs（远期）：基础设施 REITs 模式适用，但需 5-8 年现金流稳定 + 资产剥离

建议：5 年退出窗口（2027Q1 签约 + 2032Q1 退出）的路径布局 = 战略并购（首选）→ 上市预备（同期）→ 老股转让（备选）。

§23 IRR 测算（吸收 financial-analyst_20260814 §7）

核心立场

4.5 亿收购对价下，5 年退出 IRR 区间 -2.3% - 9.2%（中位数 5.9%）。关键观察：6.0 亿退出（合理预期）→ IRR 5.9% < 8% 折现率 → 净现值微正；7.0 亿退出（乐观）→ IRR 9.2% > 8% 折现率 → 净现值显著为正。

独家视角

IRR 测算核心洞察 = "5.7% 加权 IRR + 折现率 8% = 净现值微负"：

  • ✅ 乐观情景 30% 概率 + IRR 9.2% 显著超过 8% 折现率
  • ✅ 中性情景 50% 概率 + IRR 5.9% 接近 8% 折现率
  • ⚠️ 加权 IRR 5.7% < 8% 折现率 → 净现值微负
  • ⚠️ 悲观情景 5% 概率带来下行风险

建议：

  • 若预期收益率 ≥ 8% → 需收购对价 ≤ 4.0 亿（保守对价）
  • 若预期收益率 ≥ 6% → 收购对价 4.5 亿（中性对价）合理
  • 若可接受 5% 收益率 → 收购对价 5.0 亿（激进对价）合理
  • 若收购对价超过 5.5 亿 → 需重新评估，是否过度支付战略稀缺性溢价
