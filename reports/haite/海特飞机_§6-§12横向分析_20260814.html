§6 行业格局

核心立场

民用航空 MRO 行业是"重资质 + 慢变量 + 高粘性"的细分赛道，2024-2026 进入 P2F（客改货）高景气周期叠加退役飞机处置增长，行业格局呈"国资 + 民营 + 外资三方共存 + 资质壁垒决定进入门槛"特征。天津海特作为华北首家民营 CCAR-145 拆解资质企业占据细分赛道战略位置。

最强证据

全球 MRO 市场规模（来自 PitchBook 2025-04-07 深度报告）：

  • 2024 年全球 MRO 市场规模：约 1,200 亿 USD
  • 2025 年预测规模：约 1,560 亿 USD（CAGR 约 30%）
  • 2024 年全球 MRO 行业 PE 投资：24 笔交易（14 笔补充 + 6 笔平台 + 4 笔少数股权）
  • 2024 年退出：7 起（含 1 起 IPO）

中国民航 MRO 行业格局：

  • 国营主导：南航/国航/东航旗下维修基地（覆盖国有大型航司机队）
  • 民营龙头：海特高新（华北）/广州飞机维修工程 GAMECO（华南）/航新科技（华南+军机）
  • 外资：香港飞机工程（HAECO）/厦门太古飞机工程（外资合资）
  • 新进入者：润贝航科（拟通过募投进入拆解赛道，2025 募投项目）

CCAR-145 拆解资质稀缺性（来自民航局 AC-145-FS-2019-017）：

  • 拆解资质全国持有 < 30 家（公开数据估算）
  • 华北地区民营仅天津海特 1 家（来自项目委托方一手资料）
  • 申请条件：航空器拆解项目意向 + 维修许可证 + 适航批准标签 AAC-038 资格 + 授权签署人

独家视角

行业格局出现"国资整合 + 民营龙头崛起 + 外资退出"三重趋势：

  • ✅ 国资整合：民航局加强资质审批，国资背景整合带来稳定预期
  • ✅ 民营龙头崛起：海特高新、航新科技等民营 MRO 通过 20+ 年积累形成实质壁垒
  • ⚠️ 外资退出：HAECO/厦门太古等外资维修单位在 2020-2025 期间业务调整，部分产能转移至境外

天津海特作为"民营 + 稀缺资质 + 华北区域龙头"组合，在国资整合趋势中具有被收购的战略价值——天保控股（国资）作为收购方，恰好满足行业整合方向。

§7 行业空间

核心立场

中国民航 MRO 行业受"机队老化 + 退役加速 + 客改货需求爆发"三重驱动，2024-2030 年 CAGR 预计 8-12%；低空经济（CCAR-138/92 + eVTOL）作为新增长极，2030 年市场规模预计 1.5-2 万亿 CNY。天津海特处于民航 MRO 主业 + 低空经济衔接的双重增长受益位置。

驱动因素拆解：

  • 机队老化驱动：中国民航运营客机 2,000+ 架（B737-700/800 与 A320 主力机型服役 10-15 年）→ 大修需求持续增长
  • 退役加速驱动：2015-2024 全球预计 9,143 架飞机退役（年均 900+ 架）→ 拆解需求爆发
  • 客改货需求驱动：中国内地全货机仅 98 架（vs 客机 2,043 架，2014 年数据）→ 货机缺口巨大，P2F 改装持续景气
  • 低空经济衔接驱动：CCAR-138/92 + eVTOL 主机厂战略合作 → 拓展低空经济新型维修服务

独家视角

行业空间核心洞察 = "民航 MRO + 低空经济"双引擎。天津海特当前主营民航 MRO（占比 80%+），未来 3-5 年可在低空经济领域延伸：

  • 短期（2026-2027）：民航 MRO 主业持续受益 P2F 景气 + 退役处置增长
  • 中期（2027-2029）：低空经济基础设施 + eVTOL 维修服务（受 CCAR-138 通用机场 + CCAR-92 民用无人机监管驱动）
  • 长期（2029-2032）：eVTOL 整机维修 + 退役回收全产业链延伸

这一双引擎战略空间是天保控股低空公司（背后"低空经济战略"）作为收购方的核心战略动机之一。

§8 竞争对标

核心立场

A 股可比同业（航新科技/北摩高科/威海广泰）2025 估值倍数 EV/EBITDA 中位数 26x（航新 34.96x / 北摩 25.97x / 威海广泰 19.47x），显著高于全球 MRO 交易倍数（12-13x）。差异主要来自 A 股流动性 + 低空经济 + 军工溢价。天津海特在估值时享受 A 股溢价但需扣除 30% 非上市流动性折价。

  1. 同细分赛道：航新/北摩/威海广泰均覆盖航空维修/MRO（与天津海特业务赛道高度一致）
  2. 同客户结构：主要客户均为航司 + 政府/军方（海特集团含军方业务）
  3. 同地域：均为 A 股，监管环境可比（均受民航局 CCAR-145 监管）
  4. 同上市板块：航新（创业板）/北摩（中小板）/威海广泰（主板）

独家视角

竞争对标核心洞察 = "A 股估值溢价 + 30% 流动性折价"双重调整：

  • ✅ A 股估值溢价 +54-100%（流动性 + 低空经济 + 军工关税主题）
  • ⚠️ 30% 流动性折价（参考 bm-analysis 与 financial-analyst 中间报告）
  • ✅ 战略稀缺性溢价 +15-25%（CCAR-145 拆解专项 + 华北首家）
  • ⚠️ 母子公司风险折价 -10-15%（海特高新 2025 巨亏 + 保留意见）

综合调整后，天津海特合理估值倍数应低于 A 股可比中位数（26x EV/EBITDA），但高于全球 MRO 中位数（12-13x）。控制性股权价值区间 4.5-5.5 亿（详见 §11 + financial-analyst 估值方法）。

§9 技术路线

核心立场

民航 MRO 行业技术路线呈"传统大修 + 客改货 P2F + 飞机拆解 + 航材再制造"四大主线并行。天津海特全业务覆盖，形成技术护城河的同时面临新进入者（如润贝航科）的拆解资质申请冲击。

最强证据

四大技术路线：

  1. 传统大修（A320/B737 等窄体机）：成熟技术，CCAR-145 高等级；行业基准成熟期
  2. 客改货 P2F（A321 P2F / B737 P2F）：A321 P2F 是当下行业主推改装型号，P2F 改装涉及结构加强、客舱拆除、货舱门安装、应急系统升级等重大工程
  3. 飞机拆解（A320/B737/B757/B767）：按 AC-145-FS-2019-017 标准执行，关键 = 拆解件挂签授权签署人 + 拆解件登记管理系统
  4. 航材再制造：拆解件 → 适航批准签发 AAC-038 → 合格航材销售（依赖母公司航材分销资质）

天津海特技术能力清单（来自项目委托方一手资料 + 海特高新 2025 年报）：

  • 授权机型：A320 + B737-600/700/800/900 + B757 + B767（窄体主力 + 部分宽体）
  • 客改货产线：天津一期 2 条 P2F 改装线 + 2025-07 三期机库新增 3 条 P2F 产线（合计 5+ 条）
  • 机库规模：天津一期 1 号双机位窄体机机库（9,630 平米）+ 5 号公务机机库 + 2025-07 投产三期机库
  • 2026-Q3 计划：海特高新上海新产线投产（多基地协同）

独家视角

技术路线核心洞察 = "P2F 是短期主战场，eVTOL 是长期延伸"：

  • 短期（2026-2027）：P2F 行业景气 + 退役处置增长 → 天津海特 5+ 条 P2F 产线投产 + 十余条窄体机产线能力
  • 中期（2027-2030）：eVTOL 主机厂合作（海特 2025 年报披露）→ 拓展 eVTOL 整机维修 + 模拟机培训
  • 长期（2030+）：eVTOL 退役回收 + 拆解件再制造 → 全产业链延伸

技术护城河 = "P2F 全业务覆盖 + 拆解资质稀缺 + eVTOL 战略合作"三重叠加。竞争对手中：航新科技偏重机载 + 军机；北摩高科偏起落架；威海广泰偏机场设备。**天津海特 = A 股 MRO 中唯一"维修 + 改装 + 拆解"全业务覆盖的民营标的**。这一独占性是估值核心溢价来源。

§10 产业链结构

核心立场

民航 MRO 产业链 = 上游航材 OEM（波音/空客/Honeywell/Collins）→ 中游维修 + 改装 + 拆解（天津海特位置）→ 下游航司 + 物流公司 + 二手航材分销。天津海特凭借"中游+延伸至下游"的全产业链布局（航材分销平台）形成差异化竞争优势。

最强证据

产业链结构图与价值分布：

研究级解读：民航 MRO 产业链中游毛利率 8-15% 低于上游 OEM（25-40%）和下游航司（5-15%但议价能力 ★★★★），天津海特通过"中游+拆解延伸+航材分销"组合，将业务延伸至下游高毛利环节（拆解件二次销售，毛利率 25-35%）。这一价值链定位解释了为什么天津海特 2025 净利率 7.7% 显著高于海特高新合并 0.9%（8.5x 倍数）——子公司利润转移定价已被部分剥离，但 2025 年减值损失传导仍存疑。建议关注：① 拆解业务实际贡献占比（10-20% 营收 + 25-35% 毛利）；② 航材分销平台独立运营后的估值贡献（SOTP 拆分 0.23-0.38 亿）。

核心立场

天津海特位于产业链中游（MRO 维修 + 改装 + 拆解）+ 向下游延伸（航材分销），价值链定位 = 增值捕获 5-7% + 战略稀缺性 15-25% 溢价（拆解业务）。

独家视角

产业链结构核心洞察 = "中游基础 + 下游延伸"双轮驱动：

  • ✅ 中游 MRO 提供稳定现金流（民航强检 + 大修需求）
  • ✅ 下游延伸（拆解 + 航材分销）提供高毛利溢价（25-35%）
  • ⚠️ 上游 OEM 主导（航材采购议价能力 ★★★★★）
  • ⚠️ 下游航司集中度高（前 5 大航司占 60%+ 运力）→ 单一大客户依赖风险

收购方天保控股低空公司可凭借"国资背景 + 政府资源"协助天津海特向上游航材 OEM 谈判（争取更优采购条款）+ 向下游航司拓展（华北区域航司客户对接）。

§11 估值方法（吸收 financial-analyst_20260814 §2-§5）

核心立场

估值采用 DCF + Comps + Precedents 三路并进 + SOTP 业务拆分综合法。非上市标的 Precedents 路权重提高（40%）；SOTP 拆解业务溢价（18-22x EV/EBITDA）反映战略稀缺性。综合股权价值 4.5-5.5 亿（控股交易基准）。

独家视角

估值方法核心洞察 = "三路估值 + SOTP 验证 + 控股溢价调整"四步整合：

  1. 三路估值（DCF + Comps + Precedents）综合 6.10 亿（企业价值）
  2. 30% 流动性折价 → 4.27 亿（股权价值）
  3. 控股溢价 +23%（含标准 20% + 战略稀缺 10% + 整合协同 8% - 母子公司风险 15%）→ 5.25 亿

§12 商业模式（吸收 bm-analysis-shared_20260814 §1-§5）

核心立场

天津海特商业模式 = "重资产 + 资质锁定 + 平台服务型 MRO（维修-改装-拆解-航材-培训）多业务组合企业"。5 模型≥3 交叉验证（魏朱 6 要素 + 投资 3 维度 + 商业模式组合）+ 30 种模式匹配"重资产服务 + 资质 Lock-In"组合。商业模式综合评级 B+（中等偏好）。

最强证据

模式定位（来自 bm-analysis-shared §1）：

  • 5 个模式标签：① 重资产服务（★★★★★）② 资质锁定（★★★★★）③ 平台聚合（★★★★）④ 订阅服务（★）⑤ 免费增值（—）
  • 最匹配模式 = "重资产服务 + 资质 Lock-In"组合
  • 参照高端消费品标杆（稀缺供给 + 长期信用 + 渠道秩序）

魏朱 6 要素（来自 bm-analysis-shared §2）：

  1. 定位：B 端航司 + 物流公司 + 极小政府客户；需求真实高频可持续（民航强检 + P2F + 退役处置）
  2. 业务系统：控制"资质 + 制造能力 + 客户关系"三关键环节，受航司买方强势 + 母公司控制权属外力约束
  3. 盈利模式：项目制 + 长协合同；定价权 B 级（资质强但航司买方市场压制毛利率）
  4. 关键资源能力：CCAR-145 + 拆解专项 + FAA/EASA/CAAC 三认证 + 赵小东 25+ 年经验 + 母公司 35 年积累
  5. 现金流结构：EBITDA→FCF 转换率 49%（行业基准 45-60%）；2025 产能扩张期消耗现金，2026-2027 转为创造现金
  6. 企业价值：可持续性 ★★★★★ + 确定性 ★★★★ + 持续时间 ★★★★★ + FCF 规模 ★★★

9 要素画布（来自 bm-analysis-shared §3）：

  • 客户细分：国航/南航/东航 + 民营物流（顺丰/EMS/圆通/京东航空）+ 境外航司
