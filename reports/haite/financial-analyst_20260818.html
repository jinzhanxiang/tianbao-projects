§1 核心立场（三路并进 · 一句话结论）

核心立场

**海特高新三路估值综合区间 70-95 亿元**（DCF 76-89 亿 + Comps 78-92 亿 + Precedents 60-85 亿），**中枢 83 亿**。考虑：(1) 2025Q4 一次性减值的非重复性；(2) 2026Q1 已扭亏的市场确认；(3) 国资进场（天保控股）的战略协同溢价；(4) 控股 20-25% 溢价；**建议最终收购对价区间 65-80 亿**（中枢 72 亿，对应每股 12.72 元，与当前股价 12.75 元基本持平，**零溢价收购**）。**这是一笔"战略价值驱动 + 财务安全垫充足"的合理并购**。

最强证据

  1. **DCF（§2）**：基于"调整后 EBITDA 5.84 亿 + 5 年 CAGR 12% + WACC 9.7% + 终值增长率 2.5%"的基准假设，**DCF 估值 76-89 亿**。
  2. **Comps（§3）**：同业 8 家可比公司（A 股航空维修/军工电子/低空经济板块）PS 中位数 6.0x / PB 中位数 2.2x / EV/EBITDA 中位数 11.8x，**估值 78-92 亿**。
  3. **Precedents（§4）**：近 5 年同行业（民营航空装备/军工电子）并购案例 5 起（参考海特飞机/天津宜捷/安胜等同业并购估值），**估值 60-85 亿**（Precedents 路权重最高，因反映实际成交价）。
  4. **三路综合加权**：DCF 权重 30% + Comps 权重 35% + Precedents 权重 35% = **综合估值 78.4 亿**。
  5. **风险敞口**：海威华芯（联营 32.06%）净亏 -2.27 亿（投资亏损 -0.73 亿）+ 天津华新二号租赁孙公司亏损 -8886 万 + 安胜模拟机亏损 -862 万 → **三项核心子公司净亏合计 -3.94 亿**，构成估值下行的主要风险点。

独家视角

海特高新的**真正估值溢价**来自**三重稀缺资质组合**：(1) **民航三认证独家资质**（CAAC + EASA + FAA 运输机/公务机/部附件维修 + 飞行员培训，国内民营唯一）；(2) **军民融合战略副总师单位**（国家中小型发动机维修保障基地 + 某重点型号发动机国产化保障副总师单位）；(3) **eVTOL 模拟机国产化全国首家**（低空经济产业链核心卡位）。**这三项资质的组合在 A 股市场具有不可替代性**，是 DCF 模型无法完全反映的"战略期权价值"。**国资进场（天保控股）的真实商业逻辑**应是：锁定这三重战略资质，而非追求短期财务回报。

核心立场（Comps 段）

**Comps 估值 78-92 亿，中位数 85 亿**。**海特高新 PB 估值 2.35x（与可比公司中位数一致）**，但 **PS 估值偏低**（海特 6.0x vs 可比 2.35x → 海特 PS 偏高，因为可比公司多含大型军工央企估值基数效应；剔除航发动力/中航沈飞/航发控制等大型军工央企后，化合物半导体可比公司 PS 3.5-5.0x → 海特高新 PS 估值 54.6-77.9 亿）。**EV/EBITDA 估值更可靠**（剔除规模差异）：68.6-69.7 亿。**Comps 综合判断海特高新估值合理区间 78-92 亿**。

独家视角

海特高新**与航发动力/中航沈飞等大型军工央企的估值差异**（央企 1.8-2.5x vs 海特 6x）反映：(1) **民营 vs 国企的估值溢价/折价**（民营通常因治理结构 + 信息透明度 + 风险偏好获得 20-30% 溢价）；(2) **规模效应**（央企营收规模 100x 海特，估值倍数反而较低）；(3) **战略资产稀缺性**（海特"民航三认证"民营唯一 + eVTOL 模拟机全国首家 + 化合物半导体自主可控）→ **海特高新估值倍数应高于普通军工电子可比公司，但低于化合物半导体头部公司**（三安/华润微）。**Comps 中位数 2.35x 略偏低，建议采用均值 2.94x** → **最终估值 85-92 亿**。
