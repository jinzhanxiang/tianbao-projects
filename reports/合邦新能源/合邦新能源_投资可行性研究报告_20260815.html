§2 业务结构

2.1 核心业务定位

本项目核心业务为"电网侧独立共享储能"——为电力系统提供调峰、调频、备用、黑启动、需求响应等辅助服务，按"容量电价 + 电量电价 + 辅助服务费"三重收益模式经营。

2.2 业务系统（利益相关者）

📊 解读卡 · 业务系统

核心结论：三方合作 + 三类客户的双层交易结构。SPV 是价值传递的关键节点：上接投资方与运营方，下接电网调度 / 现货市场 / 辅助服务市场。

独家视角：SPV 本身没有议价权——定价权全部在电网侧。SPV 的核心价值是"把上市公司背书 + 民营地方资源转化为可调度、可结算、可融资的电网侧资产"。

4.2 核心技术差异化（易储数智赋能）

本项目技术差异化不在硬件（电池 / PCS / 升压站均为行业主流），而在 AI 数智化运营软件：

  • AI 电池健康管理系统：毫秒级电芯监测 + 异常提前预警 + 故障精准定位

这些软件壁垒来自易储数智 28+ 项目 / 17.42GWh 装机数据沉淀，是难以被快速复制的运营护城河。

中国新型储能赛道呈现"大型化 + 规模化 + 多元化"并行发展：

  • 大型化：2025 年首次实现单体吉瓦级储能电站全容量投运
  • 规模化：2025 年全年新增百兆瓦级项目超 260 个，同比增长 38.8%

9.2 磷酸铁锂路线合理性论证

本项目选择磷酸铁锂（液冷）路线，主要基于：

  1. 成本最优：0.5-0.6 元/Wh（系统价格带）vs 液流 2.5 元/Wh / 飞轮 2.9 元/W
  2. 产业链成熟：国内电池产能 200+ GWh，供应链充足
  3. 安全性：液冷 + 全氟己酮消防系统，行业主流安全方案
  4. 运营经验：易储数智 28+ 项目均采用磷酸铁锂路线
  5. 并网友好：1500V 高压液冷适配山西电网接入标准

§13 矛盾揭示

13.1 项目核心矛盾（5 个）

矛盾 1：政策依赖 vs 永续需求

表面现象：储能赛道永续需求（双碳战略 + 风光装机持续增长）

深层矛盾：永续需求不直接转化为项目现金流——项目现金流高度依赖 114 号文容量电价政策

风险敞口：政策延迟落地 → 项目回本周期 8-12 年（基线）→ IRR 5-8%（勉强可投）

破解之道：阶段性投资 + 政策面观察期 + 对赌条款保护

矛盾 2：上市公司已"出表" vs 品牌背书需求

表面现象：易储数智原为赣锋锂业控股子公司，背书能力强

深层矛盾：2025-10 易储数智已"出表"给万鑫绿能（无锡国资），赣锋持股降至 40%

风险敞口：原品牌背书逻辑减弱，治理连续性风险上升

破解之道：核实赣锋对易储数智的 43.5 亿担保是否持续有效 + 万鑫绿能决策效率评估

矛盾 3：先发优势 vs 赛道洗牌

表面现象：山西 2000 万 kW 路条实际并网 <200 万 kW，本项目已并网 = 先发优势

深层矛盾：储能赛道涌入大量新进入者（华为 / 阳光电源 / 比亚迪等），价格战风险显著

风险敞口：EPC 价格持续下行 → 后续新建项目估值下行 → 影响本项目 REITs 估值

破解之道：享受先发红利 + 加快 Pre-REITs 退出节奏（避免价格战波及）

矛盾 4：重资产投入 vs 灵活退出

表面现象：项目总投资 10 亿，属于典型重资产基础设施

深层矛盾：传统重资产项目周期 15-20 年，资本周转慢

风险敞口：若 15-20 年后电池退役 + 政策红利消退，项目可能价值归零

破解之道：Pre-REITs 3-5 年退出 + 保留 5-10% 跟投

矛盾 5：合作方利益不透明 vs 治理连续性

表面现象：三方合作架构（易储 + 合邦电力 + SPV）

深层矛盾：关联交易、运营服务费率、担保费率等公开渠道无法获取

风险敞口：利益分配机制不透明 → 可能存在利益输送或退出冲突

破解之道：尽调阶段必须索取三方合作协议 + 设置对赌条款保护

14.1 真正可投资的护城河（按优先级）

  1. 路条 + 接入通道（项目级稀缺资源）：⭐⭐⭐⭐⭐
