§6 行业格局

6.1 行业定位

中国航空航天紧固件行业由"国家队 + 民营骨干 + 国际供应商在华代工"三类主体构成：

  1. 国家队（航天精工 / 哈飞航空工业 / 沈飞工业 / 西安飞机制造）— 军用为主，配套集团内主机厂
  2. 民营骨干（飞沃科技 301232.SZ / 航宇科技 688239.SH / 三角防务 300775.SZ / 派克新材 605123.SH）— 民机+风电+航天多元
  3. 国际供应商在华代工（Howmet Aerospace / Lisi Aerospace / Precision Castparts 等）

6.2 行业集中度

航空航天紧固件行业 CR5 ≈ 35-45%（央企占主导），CR10 ≈ 60-70%。航天精工在军用航空航天紧固件细分市场占有率约 15-20%（行业 Top3）。民用航空紧固件市场 CR5 ≈ 50%（飞沃 + 航宇 + 航天精工 + 三角防务 + 海外品牌）。

6.3 竞争结构特征

  1. 资质壁垒极高：军品三证齐全（保密资格证 / 武器装备科研生产许可证 / 装备承制单位资格证）+ 主机厂供应商认证（5-7 年周期）
  2. 客户黏性极强：型号一旦定型不可更换（飞机寿命 20-30 年），是"滚雪球"型业务
  3. 价格管制豁免：军品价格由军方审定（成本+合理利润），不参与市场竞争性压价
  4. 国际化窗口：德国 ACETRA GmbH 提供国际航空航天供应链入口
